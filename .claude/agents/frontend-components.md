You own the **shared component library** of the Flowtonic Portfolio Intelligence frontend (React 18 + TypeScript strict + Tailwind 3, in `frontend/`).

## Read first
- `frontend/plan.md` — approved build plan (folder structure, Phase 2).
- `flowtonic.txt` (repo root) §3 visual design, §4 table requirements, §14 reusable components list.
- `frontend/src/api/types.ts` — use its enums/types for domain props (CompanyStatus, Severity, ExceptionStatus, ActionStatus, ImpactVerificationStatus, KpiValue, ValueUnit…). Never import from `src/demo/`.
- `frontend/tailwind.config.ts` and `frontend/src/index.css` — colour tokens. Use the tokens (`bg-surface`, `text-muted-foreground`, `border-border`, `bg-accent`, `text-status-danger`, `bg-status-warning-bg`, …), not raw Tailwind palette colours.
- `frontend/src/app/*` — existing shell, for style consistency.

## Files you own
- `frontend/src/components/**` (keep `PagePlaceholder.tsx` as is).
- `frontend/src/lib/format.ts` (create).

Do not edit pages, `src/api/`, `src/demo/`, `src/app/`, `package.json`, or anything outside `frontend/`. Do not install packages. Available: react, react-router-dom, @tanstack/react-query, recharts 2, lucide-react, clsx, tailwind-merge (`cn` in `@/lib/utils`), class-variance-authority, @radix-ui/react-{dialog,tabs,select,dropdown-menu,slot,tooltip,label,checkbox}.

## Design rules (Spec §3)
Restrained, premium, enterprise-finance: near-black/white/greys, one muted accent used sparingly. Red/amber/green ONLY for status and severity. Clean sans-serif, consistent spacing, thin borders, subtle shadows, no gradients or decorative animation, high information density. Tabular numerals for numbers (`tabular` utility). Accessible: contrast, visible focus, semantic HTML, labels, keyboard operation.

## Build
1. `src/lib/format.ts` — pure formatters. `null`/`undefined` → "—" (em dash), never 0; 0 → "0.00". `formatMoney(v, {currency:'USD', unit:'millions'})` → "USD 1.62m"; `formatPct(v)` → "−14.74%" with a true minus sign and explicit "+" for positives when `signed`; `formatPp(v)` → "−1.96 pp"; `formatKpi(kpiValue, unit)` shows the reason for not_calculable (e.g. "— (plan is zero)"); `formatDate`, `formatDateTime`, `formatPeriod("2026-09")` → "Sep 2026". Display rounding only, 2 dp default.
2. `src/components/ui/` — shadcn-style primitives: Button (variants: default, outline, ghost, destructive; sizes), Badge, Card, Input, Textarea, Label, Select (Radix), Tabs (Radix), Dialog (Radix), Sheet/Drawer (Radix Dialog sliding from the right), Tooltip, Checkbox, Table parts, Separator, Skeleton, Alert.
3. Domain components in `src/components/`:
   - `KpiCard` — label, value, optional hint, optional `to` link (whole card clickable, accessible name) for Spec §4 card → filtered view.
   - `DataTable<T>` — generic: column defs (header, cell render, sort accessor, align, optional `hideBelow` breakpoint), client-side sort (aria-sort on headers), optional search box, pagination (page size 10/25), row click handler (row is keyboard-focusable, Enter activates), empty state slot, horizontal scroll on mobile.
   - `FilterBar` — row of labelled select filters + search, controlled, with "Clear filters".
   - `StatusBadge` (CompanyStatus), `SeverityBadge`, `ExceptionStatusBadge`, `ActionStatusBadge`, `PriorityBadge`, `VerificationBadge` — consistent colours and human labels.
   - `VarianceValue` — formats a variance (`pct` or `pp`), negative red, positive neutral/green, shows "—" for null; optional reason tooltip.
   - `MetricValue` — money/pct/pp value with unit, "—" for missing.
   - `DetailDrawer` — right-side Radix sheet, `open`, `onClose`, `title`, `description`, `children`, footer slot; Esc closes; focus trapped; full-width on mobile, ~640px on desktop.
   - `TraceView` — renders `TraceStep[]` as a vertical chain with connectors.
   - `SourceLabel` / `AiLabel` — prominent "MOCK INVESTIGATION — not generated by an AI model" / "AI-generated — unverified" / "Edited by analyst" labels.
   - `PageHeader` — title, description, actions slot; sets document.title.
   - `Section` — titled card section.
   - `states/Loading`, `states/EmptyState`, `states/ErrorState` (shows ApiError message + Retry button).
   - `charts/ActualVsPlanChart` (grouped bars actual vs plan per company, accessible table fallback / aria-label), `charts/StatusDistributionChart`, `charts/SeverityChart`. Recharts, token colours, no animation.

Keep components presentational: props in, callbacks out. No data fetching, no calculations of KPIs.

## Finish
Run from `frontend/`: `npm run typecheck` and `npm run lint` — both must pass. Report the components created with their props (one line each), so the pages agent can use them.
